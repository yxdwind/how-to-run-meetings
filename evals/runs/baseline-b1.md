# 下半年工作部署会筹备方案

## 一、会议目的

总结上半年工作，部署下半年重点任务，动员各部门完成全年目标。

## 二、会议安排

- **时间**：两周后，建议上午 9:00 开始，半天。
- **地点**：公司大会议室。
- **参会人员**：公司领导班子、各部门负责人及骨干员工，建议控制在 40 人左右，营造重视氛围。
- **主持人**：运营部负责人；总经理出席并讲话。

## 三、会议议程

| 时间 | 环节 | 内容 |
|------|------|------|
| 9:00–9:10 | 开场 | 主持人介绍会议安排 |
| 9:10–9:40 | 上半年总结 | 回顾上半年经营情况（各部门补充发言） |
| 9:40–10:10 | 议题一 | 运营部汇报下半年经营目标分解，各部门讨论 |
| 10:10–10:40 | 议题二 | 市场部介绍新客户拓展专项方案，财务部参与讨论 |
| 10:40–11:00 | 议题三 | 人力部通报年中盘点结果 |
| 11:00–11:20 | 议题四 | IT 部演示新 OA 系统 |
| 11:20–11:40 | 总经理讲话 | 总结动员 |
| 11:40–12:00 | 散会安排 | 强调落实要求 |

## 四、各部门议题准备

1. **运营部**：准备目标分解表，会上组织各部门认领。
2. **市场部**：完善专项方案，会前与财务部沟通预算口径（建议提前对齐，避免会上争议）。
3. **人力部**：准备年中盘点通报 PPT。
4. **IT 部**：准备 OA 系统演示，控制在 20 分钟内。

## 五、会务准备

- 提前一周发出会议通知，写明时间、地点、参会人员和议程；
- 测试投影、话筒等设备，准备茶歇；
- 座位安排按部门分区，制作座签；
- 各部门发言提前收集 PPT，统一格式。

## 六、会后跟进

会议纪要发放各部门；重点任务列入督办清单，由办公室跟进落实进度。
