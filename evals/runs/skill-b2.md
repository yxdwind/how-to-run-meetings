# brief-2 · 带 skill 卷（走 workflow 工序：只主持轻量线）

## ① 接会问诊（六问，已知的从简）

| 问 | 答案 |
|----|------|
| 类型 | 决策会（方案评审、当场拍板） |
| 目标 | 定仓储自动化改造方案（甲/乙择一或有原则的综合） |
| 参会人 | 生产总监、仓储经理、财务总监、技术顾问（列席）；我主持 |
| 时长与形式 | 明天上午 2 小时，现场 |
| 议题与材料 | 两案已会前传阅；现金流数据在会议材料第 3 页 |
| 落实要求 | 拍板后 20 分钟部署会后动作（议程已留） |

## 会前须知（②的压缩结论）

议程已定（20+20+40+表决拍板+20）。三件会前沟通今天做完（ch07：先定准问题、会前个别沟通，不许会上突然袭击）：
1. 生产总监私下放话"乙案就是糊弄"——再谈一次：明天对方案不对人，贬损性用语按扰乱议程处理；
2. 仓储经理一被打断就沉默——打招呼：被打断≠被否定，每轮发言完我会请他把没说完的补上；
3. 财务总监未表态——把"现金流偏紧（材料第 3 页）"这个关注点会前递给他，请他第一个从资金角度发言。

## 主持提纲卡（templates/host-card.md）

### 虎头（开场七八句话内，ch03）

- **宗旨**：今天只办一件事——把改造方案定下来。
- **目的**：定方案的标准先立在这：投资、工期、人工节省、现金流承受力，四个维度当场比。
- **要求**：陈述各 20 分钟到点即停；质疑对方案不对人；我全程不先表态，最后归纳再拍板/表决。

开场立规矩：把"今天必产出：方案决议"贴在议程上（ch03：开场白立规矩）。

### 熊腰（中段控场，ch03）

- 控五样：节奏、时效、秩序、要点、质量——问答段每人每轮不超过 3 分钟，先问未发言者。
- 乱虚扯对策：顾问从传感器参数讲远＝**扯**，拽回"这跟两案差异有什么关系"；"糊弄"式贬损＝**虚**，要求换算成事实与数字；激动对峙＝秩序苗头，当场分开各自陈述、对事不对人。
- 民主集中三步骤（ch03/ch07）：**亮主张**＝两案并列陈述，我不亮偏好；**充分听取**＝点名先请财务总监（资金角度），仓储经理被打断后主动回访"你刚才的意思我理解得对吗"；**权威说法**＝见下方拍板机制，该定必给说法、不含糊。

### 拍板机制（ch07）

1. 问答 40 分钟结束，我先归纳两案在四维（投资/工期/人工/现金流）上的分歧点，请双方确认无遗漏；
2. 双方各 1 分钟最后立场陈述；
3. 举手表决；**僵局处理**：平票或无人让步时不强行表决——要么我以分管职权拍板并当场说明理由（吸收各方长项的有原则的综合，ch07），要么宣布"补充××数据后，两个工作日内续会半小时只表决"。议题确有大缺陷就不勉强通过（议题四种可能的第四种）。
4. 红线：不接受会上临时抛出的"第三方案"——临时动议不上会；新想法记录在案，另行走议题程序。

### 豹尾（结尾，ch03）

```
决议：选定＿＿案，理由三条（对应四维标准）：＿＿＿＿
落实要求（谁·做什么·刚性日期）：项目组＿＿，__月__日前报实施计划；下次检查：__月__日
两个变成自查：吸收了＿＿（财务/仓储的关键意见），注入了自己的判断＿＿
```

### 插曲处置预案（ch03）

| 情形 | 处置 |
|------|------|
| 陈述/问答超时 | 到点即停："观点可以会后书面补，时间对大家要公平" |
| 生产总监与仓储经理对峙升级 | 分开陈述各自立场→我复述双方分歧点请确认→回到四维标准比对 |
| 仓储经理被打断后沉默 | 主动回访："刚才被打断了，请你把结论说完，这在今天很重要" |
| 顾问超时讲参数 | 拽回："这一段跟两案选择的差异点在哪？"两轮不回正题就打住 |
| 议程外新话题（如顺带提其他项目） | "记入会后议题清单，今天议程已满"，不递话筒 |
| 数据争执（投资额/现金流） | 以会议材料第 3 页为准；材料没有的数据记【会后核实】，不现场赌记忆 |

