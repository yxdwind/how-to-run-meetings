# 案例 2：主持一场有争议的讨论会

> 场景标签：主持会议 · 控场 · 民主集中
> 涉及章节：ch03（如何主持会议）、ch06（可借鉴不可盲从）

## 场景

你要主持一场方案评审会，两个团队意见对立，还有一位"抢话筒"的资深同事。主持得好，会议产出共识；主持不好，要么吵散要么一言堂。本书第三讲的主持三件套：虎头熊腰豹尾、整治乱虚扯、两个变成。

## 你怎么说

> 明天我主持方案评审会，两个团队对立、有大佬容易跑题。用怎样开会的方法给我一套主持方案：开场怎么定调、中段怎么控（插话、跑题、对立意见各怎么办）、结尾怎么收，再给我一张现场速查卡。

## AI 执行路径

1. 读 `chapters/ch03-chairing-meetings.md`（虎头熊腰豹尾、整治乱虚扯、民主集中三步骤、两个变成）
2. 读 `chapters/ch06-learn-not-blindly-follow.md`（发言权、限时限次）——借罗伯特规则的控场工具
3. 按你的会议类型定制主持脚本 + 现场速查卡

## 方法论如何落地

- **虎头**：开场七八句话讲清宗旨、目的、要求——定调立规，后半场秩序省一半力
- **整治乱虚扯**：乱（迟到看手机）一有苗头马上纠；虚（发言空洞）主持人带头说实话；扯（东拉西扯）及时拽回，不回正题就打住
- **民主集中三步骤**：先亮主张 → 充分听取（对立意见让对方说完）→ 该定的给权威说法
- **总结"两个变成"**：把大家的变成自己的、把自己的变成大家的——既吸收群体智慧又有个人见地

## 关键输出片段（模拟）

```markdown
主持脚本骨架：

开场（3 分钟）："今天定三件事：选型、分工、时间表。
  先说规矩——每人发言不超 5 分钟，跑题我打断。"

控场速查卡：
┌─────────────────────────────────────────┐
│ 有人跑题 → "这个点很重要，会后单聊"（拽回）  │
│ 发言空洞 → 我先说我的真实判断（以实克虚）    │
│ 对立意见 → 让双方各说完，我来归纳分歧点      │
│ 迟到进场 → 会后单独算 600 分钟账（算术题）   │
│ 有人递话要求议程外发言 → "议程已结束，      │
│   会后向我反映"（果断收会）                │
└─────────────────────────────────────────┘

结尾（5 分钟）归纳模板：
"今天定了三件事：A（谁、何时）、B（标准）、C（时限）。
 没定的 X，下次专题会。散会后纪要 24 小时内发出。"
```
