# 主持提纲卡（host-card）

> 用途：会中执行第③步主持线的临场工具（ch03）。一页纸带进会场：开场立规矩、中段控三样、结尾给说法。
> 标注说明：出处为第三讲；卡片结构为本 skill 工程增设【增】。

## 会前须知（从①②步带过来的结论）

```
会议主题：＿＿＿＿＿＿  类型：＿＿＿＿  议程共__项：＿＿＿＿＿＿
今日必产出：□决议 □部署共识 □问题定性 □其他：＿＿＿＿
会风预案（乱虚扯对策）：＿＿＿＿＿＿＿＿＿＿
```

## 虎头（开场，七八句话内）

```
1. 宗旨：今天开会＿＿＿＿（一句话）
2. 目的：要解决＿＿＿＿、要定下＿＿＿＿
3. 要求：怎么开——发言顺序/时限/纪律：＿＿＿＿
```

开场白立了规矩，后半场秩序省一半力气（ch03）。

## 熊腰（中段控场）

- 控五样：节奏、时效、秩序、要点、质量（ch03）。
- 乱（迟到/看手机）一有苗头马上纠；虚（发言虚）以实克虚、主持人带头说实话；扯（东拉西扯）拽回正题，不回就打住（ch03）。
- 民主集中三步骤：亮出主张 → 充分听取（对事不对人，不随意打断）→ 该定的给权威说法（ch03、ch07）。
- 有不同声音正常且必要；杂音太大拉回正轨；议题本身出硬伤果断休会，调整后下次再议（ch03）。

## 豹尾（结尾）

```
归纳提炼（不过多复述）：
  ① 会议共识/决议：＿＿＿＿＿＿
  ② 落实要求：谁·做什么·什么时限——＿＿＿＿＿＿（写刚性日期）
两个变成自查：吸收了大家的＿＿＿＿，注入了自己的＿＿＿＿
```

- 总结回应不同意见但不放大分歧：正面意见采纳、负面意见解释、个别分歧求同存异（ch03）。
- 小总结再短也要有思想内涵和具体决策（ch03）。

## 插曲处置预案

| 情形 | 处置 | 出处 |
|------|------|------|
| 议程外要求发言 | "会议议程已经结束，你有事情可在会后向我反映"，随即散会 | ch03 |
| 有人迟到 | 当场算时间账（30 人×20 分钟＝600 分钟），一次较真立会规 | ch03 |
| 有人说套话贩私货 | 说两句可以，搞成主旋律就提醒再提醒 | ch03 |
| 会场突发变故 | 按议程是否已结束判断：已结束果断收会；未结束宣布议程调整 | ch03 |
