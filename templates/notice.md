# 会议通知模板（notice）

> 用途：会前筹备第②步的对外文书。核心纪律只有一条：**通知写清起止时间**（ch02）——"上午8:30开会，会议时间约1小时，9:30左右结束"，参会人心里有数，余下时间好安排工作。
> 标注说明：出处为对应讲次；模板结构为本 skill 工程增设【增】。

## 填写区

```
关于召开＿＿＿＿＿＿会议的通知

各＿＿＿＿＿＿：

  为＿＿＿＿（目的一句话，扣会议主题），定于＿＿年__月__日（星期__）
__:__ 至 __:__（会议时间约__分钟）召开＿＿＿＿会议。现将有关事项通知如下：

  一、会议内容：＿＿＿＿（议题/议程摘要，与议程筐一致）
  二、参会人员：＿＿＿＿（规模就低不就高，能小会不开大会）
  三、会议形式：□现场 □视频（分会场：＿＿） □手机会（接入方式：＿＿）
  四、会议要求：
    1. 请提前__分钟到场（或入会）签到；
    2. 请携＿＿材料（汇报提纲/数据台账）；
    3. 汇报发言每人不超过__分钟，紧扣主题、直奔要害；
    4. 会议须知（报到安排、分组、纪律）详见附件。
```

## 逐项出处

| 字段 | 规则 | 出处 |
|------|------|------|
| 起止时间 | 写清开始与预计结束时间；约多长写多长 | ch02 |
| 会议内容 | 与议程筐一致，不给议题部门化留口子 | ch02 |
| 参会人员 | 规模就低不就高 | ch02 |
| 汇报时限 | 大会发言每人约 10 分钟；视频调度会不许念现成稿 | ch02、ch13 |
| 会议须知 | 报到时间、日程、分组、纪律写明 | ch02 |

## 基层从简（ch02）

乡镇村两级：提前四五天拟好议程、至少提前两天下发通知；行政村打电话或发微信通知即可，不必行文。

## 发出前自查

- [ ] 起止时间写清（有"约__小时"）
- [ ] 议程与筹备方案一致
- [ ] 参会名单已按"就低不就高"校过
- [ ] 会期开在关节点上（时机三分类过了一遍，ch02）
