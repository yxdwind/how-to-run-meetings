# 议程筐模板（agenda）

> 用途：会前筹备第②步的主框架——先搭"筐"再装内容（ch02）。逐项排清程序，再据此选形式。
> 标注说明：出处为对应讲次；模板结构为本 skill 工程增设【增】，字段口径均取自原书方法。

## 填写区

```
会议名称：＿＿＿＿＿＿＿＿＿＿
会议主题（一句话，纲举目张）：＿＿＿＿＿＿＿＿＿＿        ← ch02：主题立足点要高、发力点要准
会议类型：□决策会 □总结部署会 □解决问题的会 □学习会 □座谈会 □现场会 □视频会 □手机会
必要性确认：为什么必须开会而不是电话/通知解决？＿＿＿＿    ← ch02 第一道关口，答不出就不开

议程（以议题为单元，逐项排程序）：                        ← ch02：议程是"筐"
  议题1：＿＿＿＿
    程序：汇报（__分钟）→ 讨论（__分钟）→ 审议（__分钟）→ 结论（__分钟）
    汇报人：＿＿＿＿  议题状态：□已会前协调 □暂缓上会
  议题2：＿＿＿＿（同上结构）
  议题3：＿＿＿＿（同上结构）

形式选择（由议程倒推）：□大会 □干部会 □现场会 □视频会 □手机会
规模（就低不就高）：__人  依据：＿＿＿＿                  ← ch02：20 人能解决就不开 50 人
会期与时机：＿＿年__月__日 __:__–__:__（约__小时）        ← ch02：时机三分类；写清起止时间
```

## 大会发言安排（如有）

发言 __ 人（5–8 人为宜）、每人约 10 分钟、紧扣主题且角度不雷同；分组讨论保证人人有机会，不许一个人说起来没完（ch02）。
