# 会议纪要模板（minutes）

> 用途：会后收口第④步（ch03/ch06）。纪律是议而有据、记录在案：决议、责任人、时限记录准确、量化到可执行（ch06 会议记录本案例）。
> 标注说明：出处为第三、六、七、十五讲；模板结构为本 skill 工程增设【增】。

## 填写区

```
＿＿＿＿会议纪要

时间：＿＿年__月__日 __:__–__:__   形式：＿＿＿＿   主持人：＿＿＿＿
参会：＿＿＿＿（记录人：＿＿＿＿）

一、会议听取了＿＿＿＿汇报，研究了＿＿＿＿。

二、会议决定（议定事项逐条列，每条三要素齐全）：
  1. ＿＿＿＿——责任主体：＿＿；事项/项目：＿＿；完成时限：__月__日前
  2. ＿＿＿＿——责任主体：＿＿；事项/项目：＿＿；完成时限：__月__日前
  3. ＿＿＿＿——责任主体：＿＿；事项/项目：＿＿；完成时限：__月__日前

三、会议要求（贯彻落实要求，含内容、步骤、时间，ch03）：
  1. ＿＿＿＿
  2. ＿＿＿＿

四、其他：未纳入决议的意见，按求同存异记录在案：＿＿＿＿（不放大分歧，ch03）
```

## 口径规则

| 项 | 规则 | 出处 |
|----|------|------|
| 决议表述 | 用会上形成的权威说法，原话口径不改写走样 | ch03（权威说法）、ch06（议而有据） |
| 责任与时限 | 量化到可执行（罚款量化到元、退赔限期到日的口径）；时限写具体日期 | ch06、ch15 |
| 数字 | 以会上实际为准，拿不准的当场确认——禁止凭印象补记 | ch06 |
| 分歧记录 | 回应但不放大：采纳的写采纳，解释的写解释，分歧求同存异 | ch03 |
| 隐性决策 | 体现在主旨报告/领导讲话中的原则与措施决策，同样记入精神与要求，同样需要贯彻执行 | ch07 |
