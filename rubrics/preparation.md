# 筹备筛（preparation）——第②步筹备方案交付前过筛

> 用法：对 [templates/agenda.md](../templates/agenda.md) 与 [templates/notice.md](../templates/notice.md) 产出的筹备方案逐项判「过/不过」，判"不过"给位置和改法。
> 出处标注为对应讲次。

| # | 检查项 | 不过的典型症状 | 出处 |
|---|--------|--------------|------|
| P1 | 必要性确认已作答且成立 | 填不出"为什么开会" | ch02 |
| P2 | 主题一句话，且经反复叩问抓住根本症结 | 主题泛化，"解决若干问题"式空题 | ch02 |
| P3 | 议程以议题为单元，逐项排清汇报→讨论→审议→结论 | 只列议题不排程序，会场现想 | ch02 |
| P4 | 专题会排足五段：主持讲话/系统汇报/补充说明/各方意见/总结定案 | 缺段，议题间转换无安排 | ch02 |
| P5 | 议题把关四查全过：权限/必要性/会签/会前协调 | 多部门议题没会签就上会 | ch02 |
| P6 | 形式由议程倒推选定，规模就低不就高 | 形式先行；20 人能解决的开 50 人 | ch02 |
| P7 | 会期过时机三分类（尽早/留足筹备/关节点），避开不合适的时点 | 假期前塞部署会；紧急会拖到白天 | ch02 |
| P8 | 通知写清起止时间与时长，提前期合规 | 只写开始时间；基层通知晚于两天 | ch02 |
| P9 | 大会发言 5–8 人、每人约 10 分钟、角度不雷同 | 发言十几人排队，角度重复 | ch02 |
| P10 | 会前检查清单过完：话筒/座签/温度/茶歇/会议须知 | 到场才发现没话筒 | ch02 |
| P11 | 落实预演：方案里已想清"会后怎么落"（部署即预演落实） | 筹备只管开会不管落地 | ch15【增】 |
