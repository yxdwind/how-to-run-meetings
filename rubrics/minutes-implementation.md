# 纪要与落实筛（minutes-implementation）——第④⑤步产出交付前过筛

> 用法：对 [templates/minutes.md](../templates/minutes.md)（纪要）与 [templates/implementation-ledger.md](../templates/implementation-ledger.md)（落实台账）逐项判「过/不过」，判"不过"给位置和改法。
> 出处标注为对应讲次；标【增】的为本 skill 从原书原则推导的硬规则。

## 纪要部分（M）

| # | 检查项 | 不过的典型症状 | 出处 |
|---|--------|--------------|------|
| M1 | 每条决议三要素齐全：责任主体＋事项/项目＋刚性时限 | 只记"会议指出"，没人接手 | ch15 |
| M2 | 决议用会上权威说法，不走样不拔高 | 纪要改写走样，执行者按错的口径干 | ch03、ch06 |
| M3 | 数字与责任人以会上实际为准，拿不准的已当场确认 | 凭印象补记数字 | ch06 |
| M4 | 时限全部精确到日期 | 纪要里出现"上半年前" | ch15 |
| M5 | 分歧按"采纳/解释/求同存异"分类记录，不放大 | 把个别分歧写成路线斗争 | ch03 |
| M6 | 隐性决策（讲话中的原则与措施决策）已记入精神与要求 | 只记显性表决，漏掉隐性决策 | ch07 |
| M7 | 纪要发出及时，直达每条决议的责任主体 | 决议出了会议室就没下文【增】 | ch15【增】 |
